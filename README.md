## 📋 Sobre o Projeto

Este projeto tem um valor especial por representar meus primeiros passos no desenvolvimento Front-end. O objetivo foi criar uma *Landing Page* funcional para um escritório de advocacia, aplicando conceitos fundamentais de estrutura e estilo.

O site apresenta:
- Apresentação do profissional/escritório.
- Áreas de atuação jurídica.
- Canais de contato e localização.

Embora seja um projeto inicial, o foco foi entregar um layout limpo, sério e responsivo, adequado à identidade visual exigida pela área jurídica.

## 🛠️ Tecnologias Utilizadas

Como um projeto de aprendizado e fundação, utilizei as tecnologias nativas da web para consolidar o conhecimento:

- **HTML5:** Para estruturação semântica do conteúdo.
- **CSS3:** Para estilização, posicionamento de elementos e responsividade.
- **Git & GitHub:** Para versionamento de código e hospedagem via GitHub Pages.
